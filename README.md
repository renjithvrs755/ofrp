# Open Fender Retrofit Project (OFRP)

OFRP is an engineering documentation project for integrating an OEM Panasonic
Fender audio system with a 7-inch MIB2 Composition Media head unit in a 2015
India-specification Volkswagen Jetta PQ35.

## Project status

The repository is establishing its engineering documentation and evidence
standard before publishing electrical or coding instructions. Existing pinout,
wake-up, speaker-mapping, and coding questions remain unverified and must not be
used as installation instructions.
