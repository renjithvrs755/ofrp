# Open Fender Retrofit Project (OFRP)

**Document ID:** OFRP-PQ35-MIB2-001  
**Version:** 0.1.0  
**Status:** Draft

## Mission
Create a vendor-neutral engineering reference for retrofitting the Panasonic Fender Audio System into PQ35 Volkswagen vehicles, beginning with a 2015 Jetta PQ35 fitted with an MIB2 Composition Media head unit.

## Project Principles
- Evidence over assumptions
- Version everything
- Trace every technical claim
- Record engineering decisions
- Keep Markdown as the source of truth

## Milestones
- v0.1.0 Project foundation
- v0.2.0 Hardware inventory
- v0.3.0 Amplifier research
- v0.4.0 Wiring and connector analysis
- v0.5.0 Bench validation
- v1.0.0 First validated retrofit
