# PHOTO-PLAN-0001 — Amplifier and Connector Reference Set

## Purpose and naming

Create orientation-preserving physical evidence for `AMP-0001`, `CON-0001`,
and the available speakers. Assign sequential IDs `IMG-0001`, `IMG-0002`, and
so on. Filenames use `<IMG-ID>_<specimen-ID>_<view>.jpg`; record date, operator,
lighting, original filename, and any nondestructive edit separately. Do not
reuse an ID or overwrite the original capture.

## Capture controls

- Use neutral, diffuse lighting and include a gray/color reference for wires.
- Use a ruler/scale in a parallel plane without hiding markings.
- Keep the camera square to connector faces; record mating versus wire-entry
  view and show `TOP`, latch, and key orientation.
- Capture an overall view before macro images and before cleaning/manipulation.
- Do not depin, open the amplifier, or alter locks merely for photography.
- Verify focus and legibility before changing the setup.

## Required amplifier photographs

- [ ] Top label.
- [ ] Bottom.
- [ ] Connector side, square-on.
- [ ] Opposite side.
- [ ] All mounting ears and brackets.
- [ ] Overall casing condition and each defect.
- [ ] Serial, hardware, software, supplier, and date label fields.

## Required connector photographs

- [ ] Mating face, square-on and oriented.
- [ ] Wire-entry face, square-on and oriented.
- [ ] Latch open, without forcing.
- [ ] Latch closed.
- [ ] Every molded cavity number/index and housing mark.
- [ ] All pigtail wires laid flat without disturbing original cavity positions.
- [ ] Wire colors under neutral lighting with color reference.
- [ ] Macro close-up of terminal population and empty cavities.
- [ ] Scale/ruler reference for housing and safe terminal dimensions.

## Required speaker photographs

For every specimen, assign its component ID before linking images.

- [ ] Front/cone view and front label, if present.
- [ ] Rear label.
- [ ] Connector and keying.
- [ ] Magnet.
- [ ] Complete mounting frame and hole pattern.
- [ ] Impedance markings.
- [ ] Tweeter labels and connector.
- [ ] Any passive components, capacitors, or crossovers without inferring value.
